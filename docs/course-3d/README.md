# GPU Boids 3D — материалы к защите (курс «3D-моделирование»)

Коротко: это интерактивная 3D-сцена, в которой стая из **100 000 агентов** (рыб или птиц)
живёт по правилам Бойдса, а **вся симуляция и весь рендер считаются на видеокарте**
(compute-шейдеры). Проект написан на **Rust + wgpu** — это кроссплатформенная реализация
WebGPU, работает и на Windows/Vulkan, и на macOS/Metal, и в браузере.

Документы в этой папке:

| файл | о чём |
|---|---|
| `01-osnova.md` | Что это за проект, из чего состоит, что считается где (CPU/GPU) |
| `02-matematika.md` | Векторы, силы Бойдса, интеграция движения, SDF, шум, атмосфера, цвет |
| `03-algoritmy-3d.md` | Spatial grid, битонная сортировка, raymarching, vertex pulling, bloom и т.д. |

## Шпаргалка: главные числа

| Что | Значение |
|---|---|
| Агентов по умолчанию | 100 000 |
| Крейтов в проекте | 5 (`boids-core`, `boids-gpu`, `boids-scene`, `boids-render`, `boids-app`) |
| Технологии | Rust, wgpu 30, WGSL, winit, glam |
| Сетка пространства (мир рыб) | 91 × 40 × 91 ячейка = 331 240 |
| Стадий битонной сортировки при 100k | 153 (массив 131 072 ключей) |
| Соседних ячеек, которые обходит агент | 27 (3×3×3) |
| Шагов raymarching океана | до 80 |
| Октав шума для рельефа | 4 (+ domain warping) |
| Цель по производительности | 60 FPS |
| Переключение мира | `TAB`, морфинг агентов 1.5 секунды |

## Что показать на защите

1. Запустить сцену, показать 100k птиц одной стаей, покрутить камеру, подвигать курсором.
2. Нажать `TAB` — показать подводный мир с рифом и рыбами.
3. Показать `docs/perf.md` с таймингами по проходам (там видно, что узкое место — симуляция).
4. Рассказать по трём документам: база → математика → алгоритмы.

## Как запустить

```bash
# интерактивно (по умолчанию 100 000 агентов)
cargo run --release -p boids-app

# один кадр в PNG без окна
cargo run --release -p boids-app -- --agents 3000 --screenshot /tmp/frame.png

# замер производительности симуляции (без окна)
cargo run --release -p boids-app -- --bench 30 --agents 100000
```

Управление: **TAB** — сменить мир (рыбы ⇄ птицы), **мышь** — притягивать/отталкивать агентов,
**левая/средняя кнопка** — переключить режим курсора.
