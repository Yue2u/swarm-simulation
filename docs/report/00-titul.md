# GPU Boids 3D — отчёт о проекте и проделанной работе

**Интерактивная симуляция стаи на 100 000 агентов на чистом Rust + wgpu: два процедурных мира, вся симуляция и рендер на видеокарте**

**Аннотация.** Проект — это GPU-резидентная симуляция флокинга (правила Бойдса) на 50–100 тысяч
агентов, написанная на Rust поверх `wgpu`. Симуляция стаи (поиск соседей через пространственную
сетку, битонная сортировка, интегрирование сил) и весь рендер выполняются шейдерами на видеокарте;
CPU за кадр только записывает uniform-буферы и собирает командный буфер, не перебирая агентов.
Сцена содержит два процедурных мира — биолюминесцентный подводный риф и небесный мир с рельефом,
биомами и деревьями, — между которыми можно переключаться по `TAB` с морфингом агентов за 1.5 с.
Проект реализован за четыре этапа («дня») плотной разработки; отчёт описывает каждый этап с
чистыми скриншотами, математический и алгоритмический аппарат, систему тестов и отдельно —
детальную проработку процедурного замка-ориентира.
