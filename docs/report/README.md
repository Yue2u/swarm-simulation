# Отчёт по проекту (md → Word)

Эта папка — исходники отчёта о проекте и скрипт сборки одного Word-документа.

## Как пересобрать

```bash
python3 -m venv /tmp/report-venv
/tmp/report-venv/bin/pip install python-docx
/tmp/report-venv/bin/python docs/report/build_report.py
```

На выходе — `docs/report/boids-report.docx` (оглавление в Word обновляется по `F9`).

## Из чего собирается

| Файл | Раздел |
|---|---|
| `00-titul.md` | титульный лист, аннотация |
| `01-vvedenie.md` | введение: что моделируется, цель, стек, ключевые числа |
| `02-arhitektura.md` | пять крейтов, конвейер кадра, CPU/GPU, память, два мира |
| `03-den1.md` | этап 1 — каркас и наивный рой |
| `04-den2.md` | этап 2 — пространственная сетка и битонная сортировка |
| `05-den3.md` | этап 3 — курсор, SDF, подводный мир, HDR |
| `06-den4.md` | этап 4 — рельеф, биомы, атмосфера, морфинг, вьюер |
| `07-zamok.md` | отдельно: процедурный замок-ориентир |
| `08-testirovanie.md` | тесты и валидация |
| `09-proizvoditelnost.md` | производительность и замеры |
| `10-itogi.md` | итоги, чего нет, направления развития |
| `11-prilozheniya.md` | репозиторий, сборка, управление, ADR |

Картинки лежат в `images/` и подставляются из markdown как `images/имя.png`.

Скрипт `build_report.py` — маленький разборщик markdown: заголовки, абзацы, списки,
таблицы, картинки с подписями и блоки кода. Правки удобнее вносить в `.md`, а не в
итоговый `.docx`.
