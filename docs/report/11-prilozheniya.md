# 11. Приложение: репозиторий, сборка и документы

## 11.1. Структура репозитория

```
crates/
  boids-core/    контракт данных, CPU-эталон, камера и лучи, поля SDF и рельефа, загрузчик WGSL
  boids-gpu/     устройство, буферы, compute-пайплайны, device-тесты
  boids-scene/   вода, пост-параметры, атмосфера, процедурный контент (рельеф, деревья, замок)
  boids-render/  граф кадров, проходы, вьюер моделей, вывод PNG
  boids-app/     окно, ввод, главный цикл, CLI, скриншоты, бенчмарк
shaders/         весь WGSL, собирается препроцессором //#include
docs/            architecture, gpu-pipeline, math, perf, ADR, материалы курса и этот отчёт
```

## 11.2. Сборка и запуск

```bash
cargo build --release
./target/release/boids                       # 100000 агентов, подводный мир
./target/release/boids --birds               # небесный мир
./target/release/boids --agents 200000       # больше агентов
./target/release/boids --strategy naive      # форсировать all-pairs для A/B
./target/release/boids --bench 120           # headless-тайминги по проходам
./target/release/boids --model castle        # вьюер модели
./target/release/boids --export-castle out/castle.obj   # экспорт замка в OBJ
```

Скриншот кадра без окна (он же точка визуальной регрессии):

```bash
./target/release/boids --fish  --agents 3000 --screenshot frame.png
./target/release/boids --birds --agents 3000 --screenshot frame.png
```

## 11.3. Управление

| Ввод | Действие |
|---|---|
| левая кнопка + перетаскивание | вращение камеры |
| правая кнопка + перетаскивание | панорама |
| колесо | зум |
| `1` / `2` / `0` | курсор: притягивать / отталкивать с закруткой / выключить |
| средняя кнопка | временный аттрактор |
| `TAB` | переключить мир (подводный ⇄ небесный) |
| `space` | пауза |
| `r` | пересоздать стаю |
| `v` | вьюер моделей (`1`..`4` — рыба, птица, дерево, замок) |
| `esc` | выход |

## 11.4. Архитектурные решения (ADR)

| Документ | Решение |
|---|---|
| ADR-0001 | Почему `wgpu`, а не готовый движок |
| ADR-0002 | Сначала all-pairs, оптимизация потом |
| ADR-0003 | Прямоиндексируемая сетка и битонная сортировка |
| ADR-0004 | HDR-промежуточный таргет и пост-цепочка |
| ADR-0005 | Raymarching окружения с записью глубины |
